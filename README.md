# Video Factory: starter

1. Install Node.js (nodejs.org) and FFmpeg (ffmpeg.org).
2. Open this folder in VS Code, then open the terminal:
       npm install
       npx playwright install chromium
       npm run video
   Your test video is now in output/video.mp4.
3. Open Claude Code in VS Code and say:

   Then continue: step 2, step 3, ...
